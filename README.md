# NorbApp Web

Official landing page for [norbapp.com](https://norbapp.com), built with Next.js, React and TypeScript.

## Development

```bash
npm install
npm run dev
```

## Production

```bash
npm run build
npm start
```

The production server binds to `0.0.0.0` and uses Render's `PORT` environment variable when available.

## Render

- Runtime: Node
- Build command: `npm ci && npm run build`
- Start command: `npm start`
- Branch: `main`
